# 수확계산기

지난 34년(1992~2025) 날씨와 그해 가격으로 내 땅의 농사를 다시 지어 보고, 얼마 남고 언제 돈이 모자라는지,
무엇을 얼마나 심으면 좋은지 계산하는 앱입니다. 화면(Next.js)이 계산 API(파이썬)를 불러 실제 엔진 결과를 보여 줍니다.

## 폴더

- `src/` 화면 (Next.js 16, React 19)
- `api/*.py` 계산 API (Vercel 파이썬 함수). 모두 `engine/service.py` 를 부른다.
- `engine/service.py` 화면 입력 → 엔진 → 화면 숫자 (만 원, 입력 면적 기준)
- `engine/analysis/` 계산 엔진. **분석 저장소(multtae_handoff/analysis)의 engine.py·cashflow.py·recheck.py 를 그대로 복사한 것**이라
  기획안 숫자와 같다. 엔진을 고칠 때는 분석 저장소에서 고치고 검증한 뒤 다시 복사한다.
- `engine/data/` 엔진이 읽는 자료 (Open-Meteo 날씨 22곳 1991~2026-11-05, 작물 소득표, 합천·강릉 저수율, 그해 실제 가격·작황)
- `dev_api.py` 로컬 개발용 계산 서버

## 로컬에서 실행

```
pip install -r requirements.txt     # numpy, pandas
python dev_api.py                   # 계산 서버 http://127.0.0.1:8000
pnpm install && pnpm dev            # 화면 http://localhost:3000 (/api/* 는 계산 서버로 넘어감)
```

## 테스트 (기획안 숫자 지키기)

```
python -m unittest discover -s tests -v    # 1분쯤, numpy·pandas 필요
```

`tests/test_plan_numbers.py` 는 기획안 데이터 부분의 숫자(대표 사례 표, 결과 1~4)를 계산 API 가 그대로 내는지,
잘못된 입력에 500 대신 안내(400)로 답하는지 확인한다. 기대값은 기획안 본문의 값이다. GitHub 에 올리면
`.github/workflows/test.yml` 이 같은 테스트를 자동으로 돌린다. 테스트가 깨지면 기획안 숫자가 바뀐 것이다.

## 배포 (Vercel)

배포 주소: https://harvest-calculator-app.vercel.app (main 에 올리면 자동 배포).
`vercel.json` 의 `builds` 로 Next.js(@vercel/next)와 파이썬 함수(@vercel/python, engine/** 포함)를 함께 빌드하고,
`routes` 로 `/api/<이름>` 을 `api/<이름>.py` 에 연결한다. Next.js 16 에서는 루트 `api/*.py` 가 자동으로 함수가 되지 않고,
`functions` 설정만 넣으면 'doesn't match any Serverless Functions' 오류가 난다. 각 `api/*.py` 는 `class handler` 를 직접 정의해야 한다. 첫 호출은 자료를 읽느라 몇 초 걸리고, 이후 계산은 1초 안팎이다.
'답이 뒤집히는 조건'(flips)은 엔진을 여러 번 다시 돌려 3~4초 걸리므로 화면에서 따로 불러온다.

## 한계 (기획안 '한계와 대응'과 같음)

- 날씨를 예측하지 않는다. 남은 기간은 지난 34년 날씨를 하나씩 이어 붙인 범위다.
- 날씨 자료는 2026-11-05까지 들어 있다. 매일 갱신하려면 자료 내려받기를 자동화해야 하고, 사업에 쓰려면 Open-Meteo 유료 이용 조건을 확인해야 한다.
- 저수지 실측 저수율은 합천·강릉만 연결돼 있다. 다른 지역은 계산한 저수율을 쓴다.
- 금액은 2024~2025년 소득 자료 기준이고, 비용 나가는 시기와 대금 입금 시기는 가정이다. 시범 농가 장부로 맞춰 보기 전 단계다.
- 계정·저장(브라우저에만 입력값 저장), 문자 알림, 상담용 A4 결과표는 아직 없다.

## 자료 출처

- 날씨: Open-Meteo Historical Weather API (ERA5 재분석, CC BY 4.0) — https://open-meteo.com/
- 저수지 일별 저수율: 한국농어촌공사 (공공데이터포털)
- 작물 소득·비용: 농촌진흥청 농산물소득자료집 2024·2025, 농사로 소득자료
- 그해 가격·수확: 국가데이터처 생산비조사·농작물생산조사
- 지원 제도: 각 링크의 2026년 안내 (지역·연도마다 다름)
